Panduan Deploy ke GitHub Pages (Hosting Gratis)
Langkah 1 — Buat Akun GitHub

Daftar di github.com jika belum punya akun. Gratis sepenuhnya.

Langkah 2 — Buat Repository Baru

Klik "New" → nama repo: database-sppg-hussa → pilih Public → Create Repository.

Langkah 3 — Upload File HTML

Simpan sistem ini sebagai index.html → klik "Add file" → "Upload files" di repository GitHub.

Langkah 4 — Aktifkan GitHub Pages

Settings repository → "Pages" → Source: Branch main, /(root) → Save → Akses di: https://[username].github.io/database-sppg-hussa

📸 Integrasi Google Drive untuk Pas Foto

1. Upload foto ke Google Drive → klik kanan → Bagikan → "Siapa saja yang punya link"
2. Salin link → paste di field "Link Google Drive" saat input relawan
3. Foto otomatis muncul di dashboard, tabel, dan podium relawan terbaik

⚠️ Catatan Penting

Data tersimpan di browser (localStorage). Untuk database permanen multi-perangkat, hubungi pengembang untuk upgrade menggunakan Google Sheets API atau Supabase.
